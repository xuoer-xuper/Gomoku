# 联机五子棋 Gomoku

双人局域网五子棋。点开一个程序，填昵称，选择 **创建房间** 或 **加入房间** 即可对战。创建房间的人就是房主，无需再开服务窗口，也无需云主机。

当前版本：**0.2.1**

## 你可以直接这样用

### 方式一：下载 exe

到 [Releases](https://github.com/xuoer-xuper/Gomoku/releases) 下载 `Gomoku.exe`，双击即可。朋友那边同样只要这一个文件，无需安装 Python。

### 方式二：源码启动

```bash
pip install -e .
python -m gomoku
```

### 方式三：自己打包 exe

```bash
build_exe.bat
```

脚本会生成 `dist\Gomoku.exe`，并复制一份到 `releases\Gomoku-<版本>.exe`（该目录已加入 `.gitignore`，不会推送到仓库）。

1. 填写昵称
2. 一方点 **创建房间**（房间号自动复制）
3. 另一方粘贴房间号，点 **加入房间**
4. 对局中可 **文字对话**、**悔棋**（需对方同意）、**再战**（需对方同意）

两台电脑需在同一机房网段或同一 Wi-Fi。创建房间时若弹出防火墙提示，请点允许；请关掉 Clash 等代理后再开房间。同一台电脑自测：把 exe 开两份，一份创建、一份加入。

完整说明见 `docs/product.md`，模块与分层见 `docs/modules.md`、`docs/architecture.md`。

## 功能

- 开始界面：昵称、创建房间、房间号加入
- 15 路棋盘、落子判定、连五胜负
- 文字聊天
- 悔棋（对方确认）
- 再战（对方确认）
- 单文件 exe，免安装

## 技术栈

| 分层 | 选型 |
| --- | --- |
| 展现层 | Tkinter 单窗口（大厅 + 棋盘 + 聊天侧栏） |
| 通讯层 | 本机内嵌 asyncio TCP + JSON；房间号编码局域网地址 |
| 服务层 | 规则引擎、悔棋、再战重置 |
| 数据层 | 内存棋盘与走子历史 |
| 分发 | PyInstaller 单文件 exe |

规则与联网逻辑仍是 Python；做成 exe 只是把解释器和程序打进一个文件，并不需要换语言。
