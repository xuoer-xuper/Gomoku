# 联机五子棋 Gomoku

双人局域网五子棋。点开一个程序，填昵称，选择 **创建房间** 或 **加入房间** 即可对战。创建房间的人就是房主，无需再开服务窗口，也无需云主机。

当前版本：**0.2.0**

## 你可以直接这样用

### 方式一：源码启动

```bash
pip install -e .
python -m gomoku
```

Windows 也可双击 `start.bat`。

### 方式二：无需安装的 exe

```bash
build_exe.bat
```

把生成的 `dist\Gomoku.exe` 拷到任意电脑，双击即可。朋友那边同样只要这一个 exe。

1. 填写昵称
2. 一方点 **创建房间**（房间号自动复制）
3. 另一方粘贴房间号，点 **加入房间**
4. 对局中可 **文字对话**、**悔棋**（需对方同意）、**再战**（需对方同意）

两台电脑需在同一 Wi-Fi。同一台电脑自测：把 exe 开两份，一份创建、一份加入。

## 功能

- 开始界面：昵称、创建房间、房间号加入
- 15 路棋盘、落子判定、连五胜负
- 文字聊天
- 悔棋（对方确认）
- 再战（对方确认）
- 单文件 exe，免安装

## 技术栈

| 分层 | 选型 |
| --- | --- |
| 展现层 | Tkinter 单窗口（大厅 + 棋盘 + 聊天侧栏） |
| 通讯层 | 本机内嵌 asyncio TCP + JSON；房间号编码局域网地址 |
| 服务层 | 规则引擎、悔棋、再战重置 |
| 数据层 | 内存棋盘与走子历史 |
| 分发 | PyInstaller 单文件 exe |

规则与联网逻辑仍是 Python；做成 exe 只是把解释器和程序打进一个文件，并不需要换语言。
