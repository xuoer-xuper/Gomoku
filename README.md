# 联机五子棋 Gomoku

Python 双人局域网联机五子棋。点「创建房间」的人就是房主，把房间号发给同一 Wi-Fi 下的朋友即可加入。不需要云服务器，也不用单独再开一个服务窗口。

当前版本：**0.1.1**

## 怎么启动

安装一次依赖（Python 3.11+）：

```bash
pip install -e ".[dev]"
```

然后每人只开一个窗口：

```bash
python -m gomoku
```

Windows 也可以双击 `start.bat`。

1. 填昵称，点 **创建房间**（你就是房主，房间号会自动复制）
2. 朋友同样运行 `python -m gomoku`，粘贴房间号，点 **加入房间**
3. 鼠标点交叉点落子，`Esc` 退出

同一台电脑自测：开两个程序，一个创建、一个加入。

两台电脑必须在同一局域网。若加入失败，检查防火墙是否放行 TCP 端口（默认从 8765 起）。

## 技术栈

| 分层 | 选型 |
| --- | --- |
| 展现层 | Tkinter 开始界面 + Pygame（pygame-ce）棋盘 |
| 通讯层 | 本机内嵌 asyncio TCP + JSON 行协议；房间号编码局域网地址 |
| 服务层 | 自研规则引擎（落子合法性、连五判定、回合） |
| 数据层 | 内存棋盘与对局快照，无数据库 |
| 规则 | 15 路自由五子棋，连五即胜，黑先 |
