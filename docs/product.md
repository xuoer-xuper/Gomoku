# 产品功能说明

## 1. 产品定位

**联机五子棋（Gomoku）** 是一款面向两人的局域网对战程序。不依赖云主机或公网 IP：其中一名玩家点击「创建房间」后，本进程即成为房主（内嵌对局服务）；另一名玩家输入房间号加入即可落子、聊天、悔棋与再战。

版本：`0.3.0`

## 2. 目标用户

- 同一机房、同一交换机或同一 Wi-Fi 下的两名玩家
- 需要在同一台电脑开两个窗口完成本地自测的开发者

## 3. 功能清单

| 编号 | 功能 | 说明 | 状态 |
| --- | --- | --- | --- |
| F1 | 开始界面 | 填写昵称后「创建房间」或「加入房间」 | 已实现 |
| F2 | 房主即创建者 | 创建房间的进程内嵌 TCP 服务，无需再开服务窗口 | 已实现 |
| F3 | 房间号 | 由局域网 IPv4 + 端口编码，客人粘贴即可加入 | 已实现 |
| F4 | 棋盘绘制 | 15 路木纹棋盘、星位、坐标、立体棋子与最新一手金圈 | 已实现 |
| F5 | 轮流落子 | 仅当前回合执子方的点击生效 | 已实现 |
| F6 | 落子判定 | 越界、已占用、未开局、错手一律拒绝并提示 | 已实现 |
| F7 | 胜负判断 | 横、竖、两斜连成五子即胜；棋盘下满且无连五为和棋 | 已实现 |
| F8 | 文字对话 | 对局侧栏收发短消息，双方同步 | 已实现 |
| F9 | 悔棋 | 一方向对方请求，须对方同意后撤销最近一手 | 已实现 |
| F10 | 再战 | 终局或对局中请求，对方同意后重置棋盘 | 已实现 |
| F11 | 断线通知 | 任一方离开，对方收到「对手已离开」 | 已实现 |
| F12 | 单文件发行 | PyInstaller 打包免安装 exe | 已实现 |
| F13 | 对战记录 | 终局自动写入本机，可按胜负筛选、按昵称搜索、查看棋谱 | 已实现 |
| F14 | 棋盘动画 | 落子缩放弹入、最新一手与连五金圈呼吸 | 已实现 |

## 4. 对局规则

- 棋盘：15×15 交叉点
- 黑棋先行
- 自由五子棋：连五即胜，不做禁手（非连珠规则）
- 不可落在已有棋子的交叉点
- 悔棋与再战均需对方确认

## 5. 使用方式

### 5.1 下载 exe

到 GitHub Releases 下载 `Gomoku.exe`，双方各开一份。

1. 填写昵称
2. 一方点 **创建房间**（房间号自动复制）
3. 另一方粘贴房间号，点 **加入房间**
4. 对局中可文字对话、悔棋、再战

### 5.2 源码启动

```bash
pip install -e .
python -m gomoku
```

### 5.3 同一台电脑自测

把程序开两份：一份创建房间，一份粘贴房间号加入。本机走回环地址，不经过防火墙。

### 5.4 两台电脑（机房 / 局域网）

两台电脑须能互相访问（同一交换机或同一网段）。创建房间的电脑若弹出 Windows 防火墙提示，必须点 **允许访问**。

## 6. 联机失败时

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 本机两窗口正常，另一台提示 `WinError 10061` 拒绝连接 | 房间号编进了代理/VPN 虚地址（如 `198.18.0.1`），或防火墙拦截入站 | 房主关掉 Clash 等代理后重新创建；防火墙点允许 |
| 连接超时 | 不在同一网段，或交换机隔离 | 换有线同一交换机，或关闭 AP 隔离 |
| 打开 exe 很慢 | 单文件解压 + 杀毒扫描 | 等数秒；可加入杀毒白名单 |

## 7. 非目标（本版本不做）

- 账号、排行榜、数据库持久化
- 公网匹配、NAT 穿透
- AI 对战、复盘文件
- 连珠禁手（三三、四四、长连）
