# 产品功能说明

## 1. 产品定位

**联机五子棋（Gomoku）** 是一款面向两人的局域网对战棋类程序。不依赖云主机或公网 IP：其中一名玩家在本机启动对局服务（房主），另一名玩家通过局域网 IPv4 地址连接后即可落子对弈。

版本：`0.1.0`

## 2. 目标用户

- 同一 Wi-Fi / 路由器下的两名玩家
- 需要在同一台电脑上用三个进程完成本地自测的开发者

## 3. 功能清单

| 编号 | 功能 | 说明 | 状态 |
| --- | --- | --- | --- |
| F1 | 连接建立 | 客户端 TCP 连接房主端口，发送 `join` 登记昵称 | 已实现 |
| F2 | 双人对局匹配 | 服务端将最先加入的两名玩家配成一局，黑先白后 | 已实现 |
| F3 | 棋盘绘制 | 15 路木纹棋盘、星位、坐标、黑白子与最新一手红点 | 已实现 |
| F4 | 轮流落子 | 仅当前回合执子方的点击生效，对方等待 | 已实现 |
| F5 | 落子判定 | 越界、已占用、未开局、错手一律拒绝并提示 | 已实现 |
| F6 | 胜负判断 | 横、竖、两斜任一方向连成五子即胜；棋盘下满且无连五为和棋 | 已实现 |
| F7 | 消息通信 | 换行分隔 JSON，覆盖加入、开始、落子、非法、结束、断线 | 已实现 |
| F8 | 断线通知 | 任一方断开，对方收到「对手已离开」 | 已实现 |

## 4. 对局规则（0.1.0）

- 棋盘：15×15 交叉点
- 黑棋先行
- 自由五子棋：连五即胜，不做禁手（非连珠规则）
- 不可落在已有棋子的交叉点
- 不支持悔棋、求和、观战、跨网穿透

## 5. 使用方式

### 5.1 同一台电脑自测

```bash
python -m gomoku server --host 127.0.0.1 --port 8765
python -m gomoku client --host 127.0.0.1 --name 黑方
python -m gomoku client --host 127.0.0.1 --name 白方
```

### 5.2 两台电脑局域网对战

1. 房主执行 `ipconfig` 查看 IPv4（例如 `192.168.1.8`）
2. 房主启动服务：`python -m gomoku server --host 0.0.0.0 --port 8765`
3. 房主启动自己的客户端，连接 `127.0.0.1`
4. 客人启动客户端，连接房主 IP：`--host 192.168.1.8`

若连接失败，检查房主防火墙是否放行 TCP 8765。

## 6. 非目标（本版本不做）

- 账号、排行榜、数据库持久化
- 公网匹配、房间号大厅
- AI 对战、悔棋、复盘文件
- 连珠禁手（三三、四四、长连）
